# 🎮 Guess The Number (Java)

A fun and interactive command-line "Guess the Number" game built with Java.

## ✨ Features
- **Dynamic Feedback**: Real-time feedback using emojis (📈 Higher, 📉 Lower, 🎉 Correct).
- **Error Handling**: Robust enough to handle non-numeric inputs and out-of-range guesses without crashing.
- **Score Tracking**: Keeps track of how many attempts it took to find the correct number.
- **Clean UI**: Stylized banners and clear instructions for a better user experience.

## 🛠️ Requirements
- Java Development Kit (JDK) 8 or higher.

## 🚀 How to Run
1. **Compile the program:**
   ```bash
   javac chw43_guessNumber.java
   ```
2. **Run the game:**
   ```bash
   java chw43_guessNumber
   ```

## 📝 How to Play
- The program will pick a random number between **1 and 100**.
- Enter your guess when prompted.
- Follow the hints to narrow down the target number.
- Try to find it in the fewest guesses possible!
